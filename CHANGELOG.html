Unreleased

  • Added a redacted native-environment preflight and verified local boot readiness for current iPhone, 11-inch iPad, Pixel-class phone, and Pixel Tablet-class targets.
  • Established and linked the private PointApp GitHub Project with its controlled workflow fields and one-active-Issue execution lane.
  • Added the governed Expo SDK 57 and strict TypeScript shell, a bundled offline foundation screen, isolated development/beta identities, reproducible native generation, local build/smoke commands, and dependency-audited CI.
