Framework and support floor

AreaDecision
FrameworkExpo SDK 57 with its supported React Native and React versions; TypeScript in strict mode; development builds for native validation.
AndroidAndroid 7+ (API 24 minimum), compile/target SDK 36 as defined by Expo SDK 57. Android phones and tablets are supported.
AppleiOS and iPadOS 16.4+. iPhone and iPad are supported.
Adaptive layoutRelease one supports handset and tablet-sized windows on both platforms. Layout follows current usable viewport width and updates during rotation, split-screen, fold/unfold, and resizing; it does not branch on device model.

Shared viewport classes

ClassLogical widthRequired behavior
CompactBelow 600Single-pane mobile composition with no clipped content or hidden essential action.
Medium600–839Tablet portrait and medium-window composition with responsive spacing and approved supporting content.
Expanded840+Tablet landscape and large-window composition with approved multi-pane layouts where useful.

These classes describe the current window, not a permanent device category. Font scale, safe areas, height, orientation, and keyboard state remain additional layout inputs.

Ownership and unresolved operational data

  • Application identifiers and store listings are organization-owned Point Community Church assets administered through PointCommunity-controlled accounts.
  • Named account holders, Apple team ID, Google Play account ID, signing certificate/profile references, keystore reference, and physical device identities remain outside source and are recorded in controlled release evidence.
  • The current Mac still needs an iOS Simulator runtime/device, Android SDK/emulator, and usable JDK before native gates can run.
